دعوة خطوبة رغدة وبشير

طريقة النشر على GitHub Pages:
1. افتحي https://github.com وسجّلي الدخول.
2. اضغطي New لإنشاء مستودع جديد (Repository).
3. اكتبي اسمًا مثل: raghdah-bashir-invitation واجعليه Public.
4. ارفعي index.html ومجلد assets كاملًا (وفيه صورة الخلفية وملف الموسيقى).
5. من Settings ثم Pages اختاري Deploy from a branch.
6. اختاري Branch: main والمجلد: /(root)، ثم Save.
7. انتظري قليلًا وافتحي رابط GitHub Pages الذي سيظهر في صفحة Pages.

ملاحظة: تشغيل الموسيقى يبدأ بعد ضغط الزائر على زر فتح الظرف، لأن المتصفحات تمنع التشغيل التلقائي قبل تفاعل المستخدم.
